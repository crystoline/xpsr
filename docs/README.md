# XPSR documentation

These guides take an XPSR application from a first project to production. They are also on the web, with search, at [xpsr.crysto.name.ng](https://xpsr.crysto.name.ng/docs/).

New to XPSR? [Getting started](GETTING_STARTED.md) builds a small API with tests, then [Deployment](DEPLOYMENT.md) covers going to production.
